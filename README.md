# 🚀 Tambo Interns Training

> 👋 **Welcome aboard!** 
> This repository is designed as your first contact with web development and will serve as the foundation for everything you will learn and work on during your next few months at the company. 
> 
> *Please follow the detailed instructions below and inform your lead if any issues arise during the process.*

---

## 🛠️ How to Fork and Clone this Repository

**1. 🍴 Fork the base project**
* Go to the main page of this repository.
* Click the **Fork** button located in the top right corner of the page.
* Select your personal account to create an exact copy of the project under your profile.

**2. 🔗 Copy the URL of your new Fork**
* Go to the newly created repository in your account.
* Click the green **Code** button.
* Copy the provided URL (you can use HTTPS or SSH).

**3. 💻 Clone the repository to your local machine**
* Open your terminal or command line.
* Navigate to the folder where you want to save the project (e.g., using `cd Documents`).
* Run the following command, replacing the URL with the one you copied in the previous step:
  ```bash
  git clone [https://github.com/your-username/repository-name.git](https://github.com/your-username/repository-name.git)
  ```

* Dirígete a la página principal de este repositorio.
* Haz clic en el botón **Fork** ubicado en la esquina superior derecha de la página.
* Selecciona tu cuenta personal para crear una copia exacta del proyecto bajo tu perfil.

**2. 🔗 Copia la URL de tu nuevo Fork**
* Ve al repositorio que se acaba de crear en tu cuenta.
* Haz clic en el botón verde **Code**.
* Copia la URL proporcionada (puedes usar HTTPS o SSH).

**3. 💻 Clona el repositorio en tu máquina local**
* Abre tu terminal o línea de comandos.
* Navega hasta la carpeta donde deseas guardar el proyecto (por ejemplo, usando `cd Documentos`).
* Ejecuta el siguiente comando, reemplazando la URL con la que copiaste en el paso anterior:
  ```bash
  git clone [https://github.com/tu-usuario/nombre-del-repositorio.git](https://github.com/tu-usuario/nombre-del-repositorio.git)
  ```
