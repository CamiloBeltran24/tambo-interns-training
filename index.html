Módulo 0: Preparación del Entorno (Git & GitHub)

Configuración Tu Portafolio de Entrenamiento

Para poder evaluar tu progreso, necesitamos que guardes todo tu código utilizando Git. Por favor, sigue estos pasos antes de iniciar los ejercicios de HTML, CSS y JS:

  1. Si no tienes una cuenta, crea una cuenta gratuita en GitHub o en GitLab (la plataforma que prefieras).
  2. Una vez dentro de tu cuenta, crea un nuevo repositorio público.
  3. Es muy importante que nombres a este repositorio exactamente así: tambourine-training
  4. A medida que vayas resolviendo los ejercicios de los módulos siguientes, ve subiendo los archivos en subcarpetas (HTML, CSS y JS) a este repositorio.
  5. Cuando termines tu entrenamiento, comparte el enlace de tu repositorio con el lider del equipo de producción para que pueda revisar tus avances.

Módulo 1: HTML Semántico (Dándole sentido a la web)

Ej 1 El esqueleto de un artículo de Blog

¡Hola! Imagina que vamos a construir la página principal de un blog. En lugar de usar puros <div>, vamos a usar etiquetas que describen exactamente qué hay adentro. Tu misión es armar la estructura de la página. Te doy unas pistas:

  • Usa un <header> para la cabecera principal, y adentro pon un menú de navegación usando <nav>.
  • Para el contenido principal, usa <main>.
  • Dentro del main, el artículo en sí debería ir en un <article> (¡este también puede tener su propio header para el título y la fecha!).
  • Añade una barra lateral con enlaces recomendados usando <aside>.
  • Finalmente, cierra la página con un pie de página usando <footer>. ¡Intenta armar este rompecabezas!

Ej 2 Un Formulario Accesible

Casi todas las páginas necesitan un formulario de contacto. Vamos a crear uno muy sencillo para pedir: Nombre, Correo y un Mensaje. Lo importante aquí es la accesibilidad.

  • Usa la etiqueta <form>.
  • Agrupa todo en un <fieldset> y ponle un título usando <legend>.
  • La clave de oro: cada cuadro de texto (<input> o <textarea>) debe tener un <label>. Para conectarlos, el atributo for del label debe ser exactamente igual al id del input. ¡Anímate a intentarlo!

Ej 3 Preguntas Frecuentes (¡Magia sin JS!)

¿Has visto esas secciones de 'Preguntas Frecuentes' donde tocas una pregunta y se despliega la respuesta hacia abajo? ¡Podemos hacer eso solo con HTML, sin programar nada más!

Te presento a dos etiquetas geniales: <details> y <summary>. Crea una sección de preguntas con dos preguntas. El summary será la pregunta (lo que siempre se ve), y el texto debajo será la respuesta (que estará oculta hasta que le hagas clic). ¡Pruébalo!

Ej 4 Ordenando datos en una Tabla

A veces necesitamos mostrar información muy estructurada, como en un Excel. Vamos a crear una pequeña tabla con los lenguajes de programación que estás aprendiendo. Tu tabla debe tener columnas para: 'Lenguaje', 'Nivel' y 'Uso principal'.

  • Empieza con <table>.
  • Usa <thead> para agrupar los títulos de las columnas (los títulos van en etiquetas <th>).
  • Usa <tbody> para el contenido de la tabla (los datos normales van en <td>).
  • Recuerda que cada fila debe ir envuelta en un <tr>.

Ej 5 Enmarcando una Imagen

Cuando ponemos una imagen en un artículo, a veces queremos ponerle un pequeño texto debajo que la describa. Semánticamente, no deberíamos dejar la imagen y el texto sueltos.

  • Usa la etiqueta <figure> como si fuera el marco del cuadro.
  • Adentro pon tu etiqueta <img>.
  • Debajo de la imagen, usa la etiqueta <figcaption> para poner el texto de la leyenda.

Módulo 2: CSS & SCSS (Dándole estilo a la web)

Ej 1 Tu primera Tarjeta con Flexbox

¡Vamos a darle estilo a las cosas! Crea un <div> con la clase .card. En tu CSS:

  1. Dale un ancho máximo (ej. 300px), un color de fondo blanco, bordes redondeados y una sombra suave.
  2. Adentro de la tarjeta pon un texto. Para que ese texto quede perfectamente centrado usa Flexbox en la clase .card (display: flex;). Explora las propiedades justify-content y align-items.

Ej 2 Galería Responsiva (CSS Grid)

Crea un contenedor para una galería (.gallery-container) con display: grid;. Tu misión es investigar e implementar esta línea de código: grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));. ¡No vas a necesitar usar media queries!

Ej 3 Botón Interactivo con Vida

Crea un botón y dale un color de fondo, color de texto y quítale los bordes que trae por defecto.

Luego, usa la pseudo-clase :hover para cambiar su color de fondo al pasar el ratón. El toque secreto: añádele a la clase principal la propiedad transition: background-color 0.3s ease; para que el cambio de color sea suave.

Ej 4 Superpoderes SCSS (Anidamiento)

SCSS es como CSS pero con superpoderes. Tu reto:

  1. Crea una variable llamada $primary-color: #a6192e; en tu archivo SCSS.
  2. Crea una barra de navegación (.navbar). Usa esa variable para el fondo.
  3. En lugar de escribir selectores separados (como .navbar ul), anida esas etiquetas *dentro* de las llaves de .navbar.

Ej 5 Mixins en SCSS (Tu propia plantilla)

Crea un mixin llamado flex-center y pon las reglas de Flexbox para centrar. Luego, crea un div con la clase .hero-section y 'pega' ese mixin usando la palabra clave @include flex-center;.

Módulo 3: JavaScript (Dándole interactividad)

Ej 1 Haciendo que la página escuche (DOM)

¡Bienvenido a JavaScript! Tenemos un botón en el HTML con id='btn-saludar' y un párrafo vacío con id='mensaje'. Queremos que al hacer clic, se muestre un saludo.

  1. Atrapa al botón y al párrafo usando document.getElementById().
  2. Dile al botón que escuche los clics usando .addEventListener('click', ...).
  3. Adentro de la función, cambia el .textContent del párrafo.

Ej 2 El Contador de clics

Vamos a hacer un clásico: un contador. Necesitas un número en la pantalla y tres botones: 'Sumar', 'Restar' y 'Reiniciar'.

  • Crea una variable let contador = 0.
  • Cuando le den a 'Sumar', agrégale 1 al contador y actualiza el texto en pantalla.
  • Cuando le den a 'Restar', quítale 1 (¡Bonus: usa un if para evitar que baje de cero!).
  • Cuando le den a 'Reiniciar', vuelve el contador a 0.

Ej 3 Filtrando una lista de contactos

Imagina que tienes este arreglo: const usuarios = [{nombre: 'Ana', rol: 'admin'}, {nombre: 'Luis', rol: 'user'}];

Necesito que me ayudes a crear un nuevo arreglo que SOLO contenga a los administradores (admin). Pista: investiga el método .filter() en JavaScript.

Ej 4 El guardián del Formulario

Tienes un formulario con un campo de contraseña (id='password'). Queremos que cuando el usuario intente enviar el formulario (evento submit), JavaScript revise si la contraseña tiene al menos 6 letras.

Si tiene menos, debes detener el envío de la página. Pista de oro: usa evento.preventDefault() dentro de un if y muestra una alerta.

Ej 5 Mostrar / Ocultar Contraseña

En HTML tienes un <input type='password' id='clave'> y un botón 'Ver'.

Tu misión: Cuando le den clic al botón, haz que JS revise la propiedad type del input. Si es 'password', cámbialo a 'text'. ¡Al darle clic otra vez, debe regresar a ser 'password'!
